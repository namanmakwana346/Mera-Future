MeraFuture Ai 🚀

AI-Powered Career Readiness & Employability Platform

MeraFuture Ai helps students with career planning, skill-gap analysis, courses, internships, resume improvement, mock interviews, and career readiness.

Features

- 🎓 Student Profile
- 🎯 Career Recommendation
- 🧩 Skill Gap Analysis
- 📚 Course Recommendation
- 💼 Internship Matching
- 📄 Resume Analysis
- 🤖 ML-based Readiness Prediction
- 🎤 Mock Interview

Technology

- Frontend: HTML, CSS, JavaScript
- Backend: Python, FastAPI
- Database: SQLite
- ML: Pandas, Scikit-learn

AI/ML

Uses Linear Regression to generate a prototype-level career readiness indicator using student academic and career data.
